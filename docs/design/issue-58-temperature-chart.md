# Issue #58 追補: 地域時系列予報 詳細ダイアログの気温折れ線グラフ 設計書

## 1. 目的・範囲

地域時系列予報（#58/#59、[設計書](issue-58-59-area-forecast-panel.md)）の詳細ダイアログで、気温の数値行を気温の折れ線グラフ行（各点に数値ラベル）に置き換える。気象庁HPの図と同じく、気温の点と時刻見出しは列の境目に、天気・風は点と点の間に置く。製造ブランチは `feature/issue-58-temperature-chart`。

対象外（変更しない）: パネル（`AreaForecastContent.tsx` のパネル表。3列・気温の数値行を含む）、parser・DB・API・`packages/shared`、朝の最低／日中の最高気温、#55・#56 の表示、#57 アメダスの表示と挙動、共用部品 `apps/web/src/map/detail/`（`DetailTimeSeriesTable.tsx`・`detail.css`）。

## 2. 根拠と確定判断

### 2.2 確定事項（オーナー、2026-09-29）

1. グラフは詳細ダイアログだけに表示する。パネルは変更しない。
2. 詳細の表に気温グラフの行を置き、表と一緒に横スクロールする。
3. 詳細の表から気温の数値行を削除し、グラフの各点に数値ラベル（例「15」。単位は見出しで示す）を添える。詳細の表は「天気」「風（m/s）」「気温（℃）」（グラフ）の3行。読み上げ（各時点の日時と気温、欠測）はグラフ行で満たす。パネルの気温数値行は変更しない。
4. 朝の最低・日中の最高気温の線は見送る（parser・DB・API は変更しない）。
5. 線と点の色は `--md-sys-color-primary`（#57 と同じ）。
6. 欠測で線を切る処理は本パネル専用の小さな関数を持つ（値 null で切る）。動的レンジは `amedasPlotRange` を再利用する。
7. 文字値だけの気温は、グラフ上では欠測と同じ「?」とし、原文は読み上げリストにだけ入れる。
8. UI監修（製造後）: 縦の目盛り（行見出し列内の数値）は省略する。行見出し「気温（℃）」の文字を他の行見出しより目立つ程度に大きくする。
9. UI監修: 天気・風は折れ線の点と点の間に入れる（気象庁HPと同じ読み方）。気温の点は列の中央から列の境目（その時刻の列の左端）へ移す。
10. UI監修: 詳細の時刻見出し「9時」等も列の境目（点の真上）に置く。共用 `DetailTimeSeriesTable` は変更しない。
11. UI監修: 最後の時刻（区間の無い気温だけの列。例 翌々日0時）は詳細では列をなくし、表の右端の境目に最後の点と時刻見出しを置く。パネル（3列）は変更しない。

### 2.3 前提（統括指示）

- ライブラリは追加しない。SVG 手描き。色は既存トークンのみ。ダークテーマ固定（ライト検証不要）。
- 想定解像度: 主 FHD 1920×1080・1920×960、副 HD 1280×720・iPad 横 1180（×820 想定）。

## 3. 実現方式

### 3.1 グラフ行: 表全幅の SVG を1セルに span（採用済み、継続）

| 案 | 評価 |
| --- | --- |
| (a) 共用部品に行種別を追加 | 共用部品の改変。回帰範囲が広い（不採用） |
| (b) 列ごとの SVG 断片を繋ぐ | 継ぎ目・段差、ラベル配置の計算が分散（不採用） |
| (c) 全幅 SVG を1セルに span | 共用部品無変更、線が連続、ラベル配置を1か所で計算（採用） |

### 3.2 境目への配置: 前後に余白列を足し、時刻見出しを CSS で半列左へずらす

列の意味を「区間」に揃える。詳細の列は次の構成にする（パネルは変えない）。

| 列 | 幅 | 役割 |
| --- | --- | --- |
| 先頭余白列 `af-pad-start` | `1.25rem`（20px） | 最初の境目の点・ラベル・時刻見出しが左上角・行見出しに隠れないための余白。天気・風・グラフ以外の中身なし |
| 区間列（既存の列から、最終の気温だけの列を除いたもの） | `4rem`（64px） | 天気・風のセル。列の左端＝その時刻の境目 |
| 末尾余白列 `af-pad-end` | `2.5rem`（40px） | 最後の境目（表の右端の境目）の点・ラベル・時刻見出しの余白 |

- 余白列は `TimeSeriesColumn` として渡す（共用部品は無変更）。天気・風の行では中身なしのセル。
- 境目 k（k = 0…M、M は区間列数）の x は、グラフ SVG 内で `20 + 64k`。境目 k の時刻は区間列 k の開始時刻、境目 M の時刻は最後の区間列の終了時刻（＝削除した最終の気温だけの列の時刻）。
- 天気・風のセルは区間列の中央にあるので、自然に点と点の間に来る。
- 途中に区間の無い気温だけの列がある場合（現行データでは発生しない）は、従来どおり区間列として残し（天気・風は空）、その左端を境目とする。最終列だけを §3.3 の規則で削除する。

**時刻見出しの位置**: `timeLabel` は文字列しか渡せないため、`.af-detail` スコープの CSS で時刻行の見出しセル（左上角を除く）に `transform: translateX(-50%)` を掛ける。セルの中身は中央揃えなので、各見出しの中心がその列の左端（＝境目）に来る。

- 先頭余白列の時刻見出しは空文字。区間列 k の見出しは境目 k の時刻「9時」、末尾余白列の見出しは境目 M の時刻（例「0時」）。
- 見出しセルは背景を持たないため、ずらしても背景のずれは生じない。時刻行の下罫線（`border-block-end`）はセルと一緒に動くので、同スコープで時刻行の `th` の下罫線を消し、見出し表 `.af-detail .detail-ts-head table` の下端に同じトークンの罫線を付け替える。
- 左上角 `th.detail-ts-corner` は sticky・背景ありで最前面のため、横スクロール時に境目の見出しは角の下に潜る（行見出しと同じ挙動）。
- 横スクロールの同期・sticky は共用部品の既存の仕組みのままで、ずらしは見出し表の中の見た目だけ。

**日付行**: 共用部品の判定で、日付は「先頭列と日付が変わる列」に左寄せで出る。列が区間になったため、日付の変わる列の左端は0時の境目と一致する。

- 先頭余白列の `at` を最初の区間列と同じ時刻にするため、先頭の日付ラベルは余白列に付く。余白列は幅20pxで、共用 CSS の `overflow: hidden` により切れるので、`.af-detail .detail-ts-head th` に限り `overflow: visible` にし、右隣の空の見出しセルへはみ出して表示させる。
- 末尾余白列の `at` は境目 M の時刻（通常は翌日0時）なので、日付が変わっていれば末尾余白列に日付が出る。はみ出しは同様に許容し、見出し表の右端で切れる分は §3.3 の余白で吸収する。
- `bodyDateBoundaries` の本文罫線は日付の変わる区間列・末尾余白列の左端（＝0時の境目）に付き、グラフ SVG 内の日付境界線（`x = 20 + 64k`）と一致する。

### 3.3 右端の扱い

- 最終の気温だけの列（時刻が直前の区間列の終了時刻に等しい列）は詳細の列から除き、その値を境目 M の点とする。等しくない場合は削除せず通常の列として残す。
- SVG の幅は `20 + 64M + 40`（余白列を含む全列の span）。最後の点の x は `20 + 64M`、右に40の余白。
- 最長ラベル「-10.5」の半幅は約17.5で、左右の余白（20・40）の中に収まる。念のため、境目0と境目 M のラベルは x を `[半幅, SVG幅 − 半幅]` に丸めて、SVG の外にはみ出さないようにする（通常は丸めが効かない）。
- 横スクロールの右端: 本文の表幅に末尾余白列が含まれるので、右端までスクロールすると最後の点・ラベル・時刻見出しの全体が見える。

### 4.2 データ

- 境目 k の気温 `t[k]`: 境目 k の時刻に一致する気温の時点セルの状態。数値（`value !== null`）、文字値のみ（`value === null`）、欠測（`missing`）、時点なし（対象外）。
- 範囲: 数値の点だけで `amedasPlotRange(values, true)`（最小〜最大に `max(幅×15%, 0.5℃)` の余白、0℃固定下限にしない。同値は ±0.5℃、数値0件は null）。
- 線分: `temperatureLinePaths(values: readonly (number | null)[], x, y): string[]`。数値でない境目（欠測・文字値・対象外）で線を切る。補間しない。

### 4.3 座標と寸法

- SVG は `width: calc(1.25rem + M×4rem + 2.5rem)`、`height: 8rem`、`viewBox="0 0 {20 + 64M + 40} 128"`、`preserveAspectRatio` 既定（縦横同倍率）。
- 点の x = `20 + 64k`（境目）。描画域 y = 30〜98、`y = 98 − (value − low) / (high − low) × 68`。
- 点 `circle r=3.5`、線 `stroke-width: 2`・`fill: none`・`stroke-linejoin: round`、色 `--md-sys-color-primary`。
- 水平の補助線は描かない（目盛りの省略に伴い削除）。日付境界の縦線は `--md-sys-color-outline-variant` の 1px を `x = 20 + 64k`（日付が変わる境目、先頭を除く）に描く。
- 列幅の検査: 先頭余白列 `1.25rem`・区間列すべて `4rem`・末尾余白列 `2.5rem` 以外の幅があればグラフを描かず、グラフ行のセルに「9時 15℃」形式の文字を並べる（値を失わない代替。通常は発生しない）。

### 4.4 数値ラベルの配置規則

- 文字: 数値だけ（例「15」「-3」「12.5」。丸めない、単位なし）。`font-size: 12px`（viewBox 単位 12）、`font-variant-numeric: tabular-nums`、`text-anchor: middle`、x は点と同じ（境目 0・M は §3.3 の丸め）、色 `--md-sys-color-on-surface`。
- 上下の選択: 点の上（ベースライン y = 点y − 8）を既定とする。隣接する線分がラベルの左右端（中心 ±16）で上側の矩形（点y−18〜点y−5）と交差し、下側の矩形（点y+6〜点y+19）と交差しないときだけ下（ベースライン y = 点y + 17）に置く。両方交差する場合は上。
- 端の保証: 上ラベルの上端は最小 12、下ラベルの下端は最大 117 で、SVG（0〜128）の内側に収まる。
- 横の重なり: 最長「-10.5」でも幅は約35で、境目の間隔64より十分狭く、隣のラベルと重ならない。
- 天気・風との関係: ラベルはグラフ行の中だけにあり、天気・風の行とは重ならない。
- 補助線が無くなったため、縁取りは日付境界線の上でだけ効く。`paint-order: stroke`、`stroke: var(--md-sys-color-surface-container-high)`、`stroke-width: 3` を継続する。
- 文字幅は**実挙動未確認**。AC-4 で実測する。

### 4.5 行見出し

- 「気温（℃）」の文字だけ。目盛りは描かない。
- 文字サイズの案: `font-size: 18px`（他の行見出しの 14px の約1.3倍）、`font-weight: 500`、`line-height: 1.3`。2行に折り返しても行見出し列（`7rem`）と行高 8rem の中に収まる。色は既存の行見出しと同じ（指定しない）。最終値はオーナーの主観確認で決める（§8 Q1）。
- 行見出しの読み上げは「気温（℃）」。

### 4.6 欠測・文字値・対象外の見せ方

| 境目の状態 | 点・線 | ラベル |
| --- | --- | --- |
| 数値 | 点あり、前後の数値の点と線で結ぶ | 数値 |
| 欠測（`missing`） | 点なし、線を切る | 描画域中央（y = 64 付近）の境目の x に「?」を `--md-sys-color-on-surface-variant` で表示 |
| 文字値のみ | 点なし、線を切る | 欠測と同じ「?」。原文は読み上げリストにだけ入れる |
| 対象外（その時刻の気温の時点が無い） | 点なし、線を切る | 表示なし |
| 数値の点が0件 | 線・点を描かない | すべて欠測なら SVG 中央に「気温の予想なし」を1つだけ表示し、境目ごとの「?」は出さない |

### 4.7 読み上げ

- SVG は `aria-hidden="true"`。
- グラフ行のセル内に、視覚的に隠したリスト（`<ul>`、`.af-visually-hidden`）を置く。境目ごとに1項目とし、境目 M（最終の点）を含む。
  - 「2026年9月28日（月）9時、気温15度」
  - 「…12時、気温欠測」
  - 「…15時、気温 {原文}」（文字値のみ。画面には原文を出さない）
  - 対象外の境目は項目を作らない。
- 時刻見出しの読み上げ:
  - 区間列の見出しは共用部品の既定（完全日付＋`timeLabel`「9時」）で、境目の時刻を読む。視覚の位置（境目）と一致する。
  - 先頭余白列は `timeLabel: ''`・`ariaTimeLabel: ''` とし、読み上げは日付だけになる（§8 Q2）。
  - 末尾余白列は境目 M の完全日付＋「0時」を読む。
- 天気・風のセルの読み上げは従来どおり「9時から12時、…」。余白列の空セルは `ariaLabel` を付けない。

### 4.8 CSS（すべて `.af-detail` スコープ、共用 CSS は変更しない）

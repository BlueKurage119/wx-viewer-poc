# バンドルサイズの見積り不足

対象: 設計担当(バンドル予算を設ける場合)。**必須の技術制約(sideEffects・パッケージ固定等)は[06-ui-md3-protocol.md](../06-ui-md3-protocol.md)を参照。**

**出典: `mj-stats-viewer`での差し戻し事例(4回連続で予算超過)。** 設計時にバンドルサイズの上限を定める場合、「UIコンポーネントを1つ置いただけの簡易プローブ」の実測値をそのまま枠にしない。フル実装が持ち込む重さ(型定義・状態分岐・アクセシビリティラベル・null安全化・ドメイン層の追加)を勘定に入れ、**簡易プローブの実測値のおおむね3倍**を枠の目安にする。

枠を超えた場合は「収まらなかった」と即断せず、意図しない取り込み(未使用コンポーネント・devコード・ライブラリ全量インポート等)が無いかを先に実測してから報告する。

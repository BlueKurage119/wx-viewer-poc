# 独立レビュー業務標準

- 対象: 統括担当、および独立レビューを担当する者(AGY・`/code-review`・Codex自動PRレビュー等)
- 関連する業務標準: 指摘を受けたあとのトリアージ権限は[01-dev-workflow-protocol.md](01-dev-workflow-protocol.md)の「外部レビュー対応の権限」
- 参照すべき関連指導文書:
  - 起動方法・依頼文の雛形・モデルの選び方・試行実績・AGY運用の癖は[G-03-external-review.md](advisory/G-03-external-review.md)

## 用語

**独立レビュー**とは、当該PRの設計・製造・検収と文脈(会話履歴、担当者の自己報告、設計時の判断の経緯)を共有しない担当が、PRの差分を読んで行うコードレビューをいう。統括担当自身によるレビューは独立レビューに数えない。

**`/code-review`**は、Claude Codeのハーネス独自のスキルである。Claude Code以外の製品(Codex・Antigravity)では使えない。AGYおよびCodex自動PRレビューは、この製品依存を持たない。

## 1. ゲート(必須)

- **統括担当は、マージを提案する前に、独立レビューを1本以上通す。**
- 次のいずれかに当たる場合は、省略できる。
  - 変更が`docs/**`配下の`*.md`のみである。
  - 統括担当が省略を提案し、ユーザーが承認した。
- Codex自動PRレビューは、独立レビューに数える。
- 統括担当が独立レビューを起動する場合は、方式(AGY/`/code-review`の別、モデルまたはレベル)をユーザーが指定するか、統括担当が提案してユーザーが承認したものによる。
- 再レビューの要求は、ユーザーの明確な指示なく行わない(01の「外部レビュー対応の権限」のとおり)。

## 2. レビュー担当の権限境界(必須)

- レビュー担当は読むだけとする。ファイルの編集、コミット、push、PRへのコメント投稿をしない。
- 結果は統括担当への報告として返す。PRへの投稿が必要な場合は、統括担当が行う。

## 3. 指摘の真偽判定(必須)

- レビュー担当の指摘は、統括担当が実際のコードで真偽を判定してから、ユーザーに提示する。鵜呑みにも却下にもしない。
- 判定した結果(真・偽・判断保留)と、その根拠として確認したコードの箇所を、指摘ごとにユーザーへの提示に含める。
- 真と判定した指摘のトリアージ(要対応・先送り・無視)は、01の「外部レビュー対応の権限」に従う。
